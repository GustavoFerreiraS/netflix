# Projeto Netflix (Atividade)

Este repositório foi criado como uma atividade prática para desenvolver uma **página estática inspirada no layout da Netflix**, utilizando HTML e imagens.

## 🧩 Estrutura

- `index.html`: Página principal do projeto.
- `bob.html`: Página adicional criada como parte da atividade.
- `img/`: Pasta contendo as imagens utilizadas no projeto.

## 🛠️ Tecnologias Utilizadas

- HTML5
- Recursos visuais (imagens)

## 🎯 Objetivo

Reproduzir uma interface visual semelhante à da Netflix como exercício de prática em HTML, organização de pastas e estruturação básica de páginas web.
